# Jay Lin — Portfolio

[Open the website](https://shijie.vercel.app/)

The current website lives in **app/** and uses React / Vite. It includes the interactive office opening, systems design portfolio, Roco case and working sandbox, art desk, all 25 artworks and bilingual About/contact views.

```sh
cd app
npm ci
npm run dev
```

See [app/README.md](app/README.md) for build, verification and deployment instructions. Vercel Root Directory remains `app`; publishing from `main` updates the existing project and its connected domains.

The prior Next.js application is preserved in Git history and at tag `backup/pre-v16-20260911`. The repository's older reference images, resume files and notes remain outside the application; the new build does not import them.

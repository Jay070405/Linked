# 英雄联盟互动案例页

本地路由：`/systems/league-of-legends`。运行 `npm run dev -- --port 4317` 后访问 `http://127.0.0.1:4317/systems/league-of-legends`。本轮未公开部署。

内容基准为飞书文档 `XvDVdcj5HonPppxZosWuCGRUtHc`，读取版本 **121**，研究资料截止 **2026-09-18**。完整中文快照与读取元数据位于 `public/assets/lol/source-zh.md`、`source-meta.json`。快照仅将 13 个飞书图片地址替换为本地图片引用，正文保留。旧 PDF 与旧网页未接入。

## 实现位置

- `src/pages/LeagueCase.jsx`：章节、演示状态、图片弹层与滚动定位。
- `src/pages/lol-content.js`：双语章节定义、完整依据、来源、图注、内容映射与决策表。
- `src/pages/lol-model.js`：通行证估算、匹配分档、双方共享英雄池及预设阵容。
- `src/pages/lol-case.css`：银灰阅读界面、胶囊导航、客户端演示和响应式布局。
- `PortfolioPages.jsx`：独立懒加载分发；`portfolioData.js`：启用现有作品 slug。
- `SiteNavigation.css`：修复原菜单在 621–1024px 时受 `left:0` 干扰、关闭后仍露出的定位问题。

页面使用现有 Motion，旧章向左退场，新章从右侧减速进入。退出阶段读取最后一次选择；进入中再次选择只保留最终目标。父组件保存演示与展开状态。滚动定位使用现有 `.portfolio-page-viewport` 和悬浮导航的实际高度。减少动态时直接切换，章节按钮支持方向键、Home、End。

所有演示与媒体均在本地运行，无登录依赖、无新增后端。图片弹层使用原生 `dialog`，Esc 关闭并恢复焦点。中文截图配双语图注。主要画面由已有 HTML 去除红框后重新截图，保留原始标注图供深读。

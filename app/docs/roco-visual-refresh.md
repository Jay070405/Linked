# 洛克王国案例页：视觉与交互修订

实施日期：2026-09-22。用户确认英雄联盟新版后，授权将同一视觉语言用于洛克王国。

## 范围与实现

- 路由：`/systems/roco` 与 `/systems/roco/model`。本地审阅，未部署。
- `RocoExperience.jsx`：复用现有 GlassSurface、ExpressiveTitle 与 Motion，实现首屏阅读预览、轻微指针倾斜、浮动玻璃信息卡、章节胶囊、分段控件与 S5 步骤说明。
- `roco-experience-content.js`：双语阅读标题、入口说明和与既有规则对应的步骤讲解。没有改写源数据及原始模型。
- `roco-experience.css`：中性黑白银灰、玻璃控件、标题层级、hover 与 focus 状态、手机布局和减少动态回退。
- `RocoCase.jsx`：先展示实机操作与规则步骤；S3 与 S5 完整流程图默认直接展示，保留原图放大入口；现有配置表、原文链接、PDF 和本地原型入口保留。修正滚动导航高亮与顶部定位，窄屏自动露出当前章节。
- `RocoModel.jsx`：更新标题、预设按钮、收入口径控件与呈现样式；原有计算、校准、台账与 sessionStorage 行为保留。
- `roco-pages.css`：将界面旧色值中性化，保留具有说明意义的黄色策划备注列。原始图片、流程图、封面与嵌入原型素材未改色。
- `roco-model.test.mjs`：为 Motion 的服务端渲染补充标准宿主 API（时钟、微任务、计时器与 process），没有删减或放宽既有断言。

继续使用已安装 humanizer、humanizer-zh、stop-slop 和 design-taste-frontend。将泛化口号改为具体玩家问题、操作和验证范围；保留原始规则、参数、来源及证据限制。

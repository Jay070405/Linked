# 樱花收尾动效重做 — 设计规格

**日期**: 2026-09-27
**分支**: `finale-motion`(基于 `origin/main` @ `495813f`)
**状态**: 设计完成,用户已授权按本规格直接实施

---

## 一句话

把「作品区之后的樱花收尾」从一串网页元素的淡入淡出,改成一支像 AE 剪出来的电影片头:镜头有质量和惯性,每一镜有自己的速度曲线,字幕从遮罩后切入,黑场是一次真正的匹配剪辑,整段压着同一层胶片后期。

## 目标与成功标准

- **连续**:滚轮逐格滚动时镜头不再一顿一顿,停手后带余势滑停。
- **同步**:3D 镜头、背景、字幕读同一个平滑后的进度,任何时刻都不会各走各的。
- **有剪辑语言**:遮罩切入的字幕、跟焦(rack focus)、光圈收拢式的黑场、再亮起后才拉远。
- **有后期**:胶片颗粒、镜头暗角、花朵背后的柔光晕,统一覆盖整段。
- **不更卡**:脚本化滚过整段,桌面端 p95 帧时间不高于改动前。
- **不回退**:「减少动态效果」模式、WebGL 不可用、手机端都保持可用;其余所有测试照常通过。

风格方向(用户选定):**电影片头感**——慢、克制、有呼吸。参考 Apple 产品片、A24 片头。

## 保留不变

- 3D 樱花模型、绘画材质、整条镜头叙事(雕塑 → 钻入花瓣 → 黑场理念 → 拉回 → 回到开始)。
- 全部文案。
- 收尾段总长度(`680vh`,手机 `610svh`)与站点其余部分的全部动效。
- `.quiet`(减少动态效果)模式下的静态深色排版。

## 现状诊断(为什么不像 AE)

1. **滚动一比一直接驱动镜头,没有阻尼。** 滚轮一格约 100px,镜头就跳一下。
2. **节奏被写了两遍。** `usePostJourney.js` 算一遍文字和背景,`BlossomScene.jsx` 用自己的魔法数字再算一遍镜头;「变黑」在两个文件里各算一次,只是恰好对齐。
3. **全场只有一条缓动曲线**(smoothstep),所有元素节奏性格相同。
4. **文字只会淡入 + 上移**;阅读文字逐字「跳亮」(硬切色值,外加 `transition: color .18s` 拖出一层糊)。
5. **零后期**:没有颗粒、暗角、景深、光晕。
6. **额外的卡顿源**:收尾标题套着 `ExpressiveTitle`,它在每个祖先上用 `MutationObserver` 监听 `style`;滚动循环每帧都改这些祖先的 `style`,于是每帧都触发一次逐层 `getComputedStyle`。
7. **桥段那片花瓣是 CSS 圆角 `div`**(`border-radius:70% 25% 68% 30%`),放大 3 倍后像一颗药片;紧接着却是精细的 3D 樱花,风格断裂。
8. 斜着飘过去的文字丝带是模板化的跑马灯。

## 架构

```
            滚动 ──► ScrollTrigger(scrub 1.2,带惯性)
                           │
                    GSAP 时间轴(时长 100 = 收尾段滚动的 100%)
                    ├─ clock.p:0→1 线性 ─► channels(p) ─┬─► BlossomScene(镜头、材质)
                    │                                   └─► DOM 通道(背景、光圈、跟焦、颗粒、光晕、阅读光标、导航色调)
                    └─ 字幕片段:遮罩切入 / 切出,各自的曲线与错位
```

| 单元 | 职责 | 使用方 | 依赖 |
|---|---|---|---|
| `finale-cut.js` | **剪辑表** `CUT`(每一镜的起止)、曲线名 `EASE`、纯函数 `channels(p)` 把平滑进度换算成全部连续通道值 | `Finale.jsx`、`BlossomScene.jsx`、测试 | `gsap.parseEase`(只取曲线,无 DOM) |
| `Finale.jsx` | 收尾段的标记 + 导演时间轴(`useLayoutEffect` + `gsap.context`,卸载时 `revert`)。持有时钟,不再从 `App` 传入 | `App.jsx` | gsap、ScrollTrigger、剪辑表、BlossomScene |
| `BlossomScene.jsx` | 只负责画。读 `getChannels()`,不再自己从进度算阶段;待机微晃仍走自己的时间 | `Finale.jsx` | three、剪辑表(`progress` 属性的兼容回退) |
| `finale.css` | 收尾段样式与后期层;遮罩、颗粒、光圈这些原语不带收尾前缀,之后别的段落可以直接用 | `Finale.jsx` | — |

**连续值用纯函数,离散编排用时间轴。** 镜头距离、黑度、光圈这类随进度连续变化的量放在 `channels(p)`:可以在 Node 里直接测,BlossomScene 和 DOM 读到的是同一组数。字幕这类需要逐行错位、切入切出的编排交给 GSAP 时间轴——它本来就擅长这个。两者挂在同一条被 scrub 的时间轴上,所以天然同步。

**`usePostJourney.js`**:删除收尾那一整块和 `blossomProgress` 参数;开场、作品区、桥段逻辑不动(桥段花瓣的翻飞除外,见下)。收尾段本身是 CSS `sticky`,ScrollTrigger 不需要 `pin`。

**可复用底座刻意不做过头**:这次沉淀的是零件(剪辑表写法、`channels` 模式、遮罩/颗粒/光圈原语、曲线预设)。不把时间轴写成通用框架——等第二个段落真要用时,从两个真实用例里抽,比现在猜更准。

## 分镜(剪辑表)

进度 `f ∈ [0,1]` 是收尾段滚动的比例。下表区间可以重叠——就像 AE 里错开的图层。

| 镜 | 区间 | 画面 | 曲线 |
|---|---|---|---|
| **入场** | 段落顶部从视口底边升到顶边(独立触发器) | 樱花随页面升起时带视差:`y 14% → 0`、`scale .9 → 1`,背后光晕同时亮起 | `power2.out` |
| 静置 | 0.00–0.10 | 完整的樱花雕塑 + 邀请语,待机微晃 | — |
| 邀请语退场 | 0.07–0.15 | 两行从遮罩内向上切出 | `expo.in` |
| **钻入** | 0.13–0.40 | 镜头推向花瓣表面(对数距离插值,保留现有做法)。先慢后快再贴近时刹住 | `expo.inOut` |
| 光晕扩散 | 0.13–0.40 | 粉色光晕在花瓣到达画面边缘之前先漫出去,像光渗 | 跟随钻入 |
| **标题切入** | 0.17–0.26 | 「从一个念头 / 到一个世界」逐行从遮罩下切入,错位 0.8;字距从 `+.06em` 收到 `-.07em`,模糊 `8px → 0` | `expo.out` |
| 标题停留 | 0.26–0.35 | 静止可读 | — |
| **跟焦** | 0.20–0.40 | 标题在焦时花瓣虚化:画布 `blur 0 → 5px`(0.20–0.27),停住,再 `5px → 0`(0.34–0.40)焦点回到花瓣。画布同步放大 1.5% 藏住模糊边缘 | `power2.inOut` |
| 标题切出 | 0.35–0.42 | 逐行向上切出并虚化 | `expo.in` |
| **光圈收拢** | 0.37–0.47 | 暗角从画面边缘向中心收拢,像灯一圈圈熄灭 | `power2.inOut` |
| **匹配剪辑** | 0.40–0.48 | 已经贴满画面的花瓣自身的颜色沉入黑色(材质 `uStoryDark`,上限 0.94,留一丝深梅色纹理当「念头内部」的底);DOM 背景在被完全遮住时同步变黑 | `power2.inOut` |
| 章节眉题 | 0.48–0.53 | 「03 / PHILOSOPHY & PRACTICE」字距收拢、淡入 | `expo.out` |
| **景深层** | 0.47–0.77 | 四个方向词(WORLDBUILDING · NARRATIVE …)以极大、极细、失焦(`blur 2.5px`)的字体在文字后方缓慢横移,最大不透明度 0.07——取代原来斜着的跑马灯 | 滚动驱动 + 80s 环境漂移 |
| **阅读** | 0.51–0.69 | 阅读光标扫过正文:每个字的亮度由光标位置连续插值,前沿带 6 个字宽的柔和过渡,不再逐字跳亮 | 线性 |
| 补充说明 | 0.62–0.70 | 说明文字与「认识我 ↗」从遮罩切入 | `expo.out` |
| 理念退场 | 0.71–0.76 | 文字整体上浮、变暗、虚化 | `power2.in` |
| **重新亮起** | 0.74–0.84 | 光圈打开,花瓣从黑里重新亮回粉色——**此时镜头仍贴着花瓣** | `power2.inOut` |
| **拉远** | 0.80–0.96 | 镜头退回全景,五片花瓣同时向内收拢成花苞 | `expo.inOut` |
| 结尾 | 0.90–1.00 | 「Back to a beginning.」从遮罩切入,副标题随后 | `expo.out` |

**关键顺序约束(匹配剪辑的正确性)**:背景只在花瓣完全盖满画面时改变颜色。去程先钻到底(0.40)再变黑;回程先亮回来(0.84)再拉远(0.80 起步时近乎为零)。形式化为测试:任何 `dark > 0.02` 的时刻都必须 `close > 0.7`(在当前相机参数下,`close ≥ 0.7` 时画面被花瓣完全覆盖)。原实现在回程时是边拉远边变亮,这条约束能防止以后调参时不小心退化回去。

## 后期层

自下而上:

1. `finale-ground` — DOM 背景色(浅 ↔ `#09090b`)
2. `finale-halo` — 花朵背后的柔光晕,粉色径向渐变,只用 `transform` + `opacity`(合成器处理,不触发重绘)
3. `blossom-wrap` — WebGL 画布;跟焦时加 `filter: blur()`,其余时间 `filter: none`
4. `finale-iris` — 暗角 / 光圈,视口大小的径向渐变,半径与浓度用 CSS 变量驱动。常态下是很淡的镜头暗角
5. 文字层 — 景深层 → 理念 → 标题 → 邀请语 → 结尾
6. `finale-grain` — 胶片颗粒,盖在最上面统一整段质感:`feTurbulence` 灰度噪点贴图,`steps(8)` 抖动 ≈ 胶片的逐帧颗粒;浅底 5%、黑底 10%。段落不在视口内或弹出作品页时暂停动画

不做 WebGL 后处理(真景深、Bloom、EffectComposer):透明底画布上做 Bloom 很麻烦,真景深太贵;跟焦 + 光晕 + 暗角 + 颗粒已经给出九成的电影感,成本低一个量级。

## 字幕系统

- **遮罩行**:`<span class="mask"><span class="mask-in">…</span></span>`。`.mask` 裁切,`.mask-in` 在时间轴上从 `yPercent: 110` 切入。行是手写的——文案由我们掌控,不需要运行时分行库。`.mask` 底部留 `.08em` 余量,避免下行字母被裁。
- **初始隐藏态只由 JS(`gsap.set`)施加**。减少动态效果或脚本失败时,文字按原样可读;组件卸载时 `gsap.context().revert()` 清空全部内联样式。
- **阅读光标**:只在亮度真正变化时写 `style.color`(按字缓存上一帧的值),移除 CSS `transition`。
- **收尾段不再使用 `ExpressiveTitle`**——它是一次性按时间播放的进场,和可倒放的滚动时间轴冲突,还是每帧卡顿源之一。站点其他地方的 `ExpressiveTitle` 不动。

## 桥段花瓣

- `.petal` 改成真正的樱花瓣轮廓:用 SVG `mask` 做出圆润的倒卵形和顶端那道缺刻(樱花瓣的标志),保留原有的渐变着色,中间一条细脉。**只改 CSS**,全站所有 `Petal`(桥段、跨段飞行的那片、花瓣场)一起升级,标记不动。
- 空中的花瓣要**翻飞**,不只是平面旋转:桥段花瓣和跨段花瓣的变换里加入 `perspective` + `rotateX` / `rotateY` 的摆动,翻到侧面时自然变薄。

## 降级与适配

| 情况 | 处理 |
|---|---|
| 减少动态效果(`.quiet`) | 不建时间轴、不加颗粒动画;沿用现有静态深色排版。BlossomScene 读 `channels(0)`,停在雕塑态 |
| WebGL 不可用 | 画布不出现;时间轴照常驱动文字、背景、光圈,叙事仍然完整 |
| 手机(< 700px) | `scrub 0.8`(触控滚动本身有惯性,再加太多会发飘);不做画布跟焦模糊;颗粒更淡;景深层字号收小 |
| 切换语言 | 时间轴随文案重建,ScrollTrigger 按当前滚动位置恢复 |
| 弹出作品页 | 画布已有暂停逻辑;颗粒动画同步暂停 |

## 性能预算

- 每帧 DOM 写入只发生在值变化时;连续通道写 CSS 变量或 `transform` / `opacity`,只有光圈渐变需要重绘一个视口大小的图层。
- 画布模糊只在跟焦区间开启。
- 验证:脚本化滚过收尾段(逐帧推进滚动位置),记录 `requestAnimationFrame` 帧间隔的 p50 / p95 / 超 33ms 帧数,改动前后各测一次。桌面端 p95 不得高于改动前。

## 实施修订(基于实测)

以下几处与上文不同,每一处都有测量依据。测量环境:本机 RTX 4070 Ti SUPER,无头 Edge(D3D11、无垂直同步),每轮都是全新配置文件的「首次访问」。

| 设计 | 实际交付 | 依据 |
|---|---|---|
| 标题切入 `blur 8px → 0`,切出 `blur 6px` | 去掉模糊;保留遮罩上滑与字距收拢 | 在滚动中途首次创建 CSS 滤镜的渲染表面,时间轴 0.21 处约 33ms 顿挫 |
| 跟焦模糊上限 5px | 上限 2px,另加画布不透明度降到 88% | 3px 仍有 32ms 顿挫;≤2px 时合成器不走降采样路径,零顿挫。不透明度是零成本的补偿 |
| 理念退场带 `blur 6px` | 只淡出 + 上浮 | 同一机制,0.74 处顿挫 |
| 景深层 `filter: blur(2.5px)`,不透明度 0.07,重复 4 遍 | `text-shadow` 做失焦,0.05,重复 2 遍 | 0.49 处顿挫;宽度 28,251 → 14,099px;实拍中 0.07 与未读文字同亮,抢正文 |
| 颗粒与常态暗角全程存在 | 入场最后 30% 渐入、离场最初 30% 退出;颗粒不透明度下限 0.001 | 实拍入场时舞台顶边有色差接缝(修后实测亮度差 0.00);颗粒从 0 起步会把首次光栅化推迟到入场中途,50ms 顿挫 |
| 媒体条件 `min-width:700px` / `max-width:699px` | `v16.css` 自己的 `max-width:700px` 与其否定 | 700px 时 CSS 已是手机布局、时间轴却走桌面;699–700 之间的小数宽度(浏览器缩放)两个条件都不匹配,时间轴不建 |
| 花瓣路径(初稿) | 最宽处在上三分之一、花托内凹收窄、浅 V 缺刻 | 初稿放大 3 倍像爱心或树叶 |
| CTA 直接淡入 | 淡入作用在外壳 `.finale-cta` 上 | `.text-link` 自带 `transition: opacity .25s`,会把滚动驱动的不透明度拖慢 250ms,并压住悬停态 |
| 清理时回写导航色调 | 每次构建前按 `reduced` 重设基准色调 | GSAP 还原中途的时间轴会渲染回首帧,首帧的 `apply()` 覆盖了 React 刚提交的 `dark` |

**结果:** 首次访问与改动前的基线逐帧一致(唯一超过 20ms 的一帧是两者共有的入场帧);稳态 p95 均为 7.0–7.2ms;两轮完整滚动零控制台报错。

## 第二版:念头 → 世界(取代上文的樱花分镜)

**起因(用户反馈)**:第一版「看不出区别、少了高级感」;「那个樱花就很简陋,直接把那个地方改掉」。对照截图确认:第一版只改了节奏曲线和很淡的后期,画面仍是同一朵花、同样的黑字,还多出两帧难看的画面(一团模糊粉色、一整屏平涂粉色)。

**诊断**
1. 字幕被滚动条拖着走,缓动曲线被用户的滚动速度抹平,AE 里的「节奏」出不来。
2. 文案讲的是「一个念头 → 一个世界」,画面从头到尾只有一朵花,主题没有被画出来。
3. 樱花本身与全站黑白调不一致,且造型粗糙。

**新分镜**(`CUT` / `HIT` 见 `finale-cut.js`,点阵见 `world-points.js`,渲染见 `WorldScene.jsx`)
| 进度 | 画面 |
|---|---|
| 0–.08 | 白纸中央一颗墨色珍珠(两万多个点组成的小球),外圈碎点绕行、呼吸 |
| .08–.25 | 镜头推近;「从一个念头，」「到一个世界。」逐字升起并收拢字距(按时间播放);跟焦把珍珠推到焦外 |

**关键决定**
- **字幕改为「到点播放」**:滚动只决定何时触发,动画本身按秒播放(逐字 1.15s expo.out,错开 .045s);往回滚会反向收回。滚动持续驱动的只剩镜头、点阵和光线。
- **夜色画在 WebGL 里**:墨色圆和点的反色用的是同一个圆、同一套设备像素坐标,边缘严丝合缝;DOM 底色只在圆盖满后才跟着变黑,WebGL 不可用时直接跟随夜色,文字不会白底白字。
- **暗角等夜色盖住纸面(night ≥ .75)才出现**,免得扩圆时纸面四角发灰。
- **字距用 CSS 变量补间**(`--track`):GSAP 在两个 em 负值之间换算时会落到 `0px`,实测英文标题因此散开 150px。
- 去掉:樱花模型与水彩材质(`BlossomScene.jsx`、`blossom-painted-material.js`)、粉色光晕层、失焦的学科名飘带层。

**实测**(RTX 4070 Ti SUPER,无头 Edge,全新配置文件):稳态 p50 6.4ms / p95 6.9–7.1ms,零长帧(>33ms);首访仅入场处一帧 26–49ms,第一版就有这一帧;两轮控制台零报错。桌面 1440×900、手机 375×812、英文版、减少动态四种情况逐帧看过。

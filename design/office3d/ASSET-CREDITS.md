# Office asset credits

This local scene contains editable Blender geometry and the following downloaded CC0 assets from Poly Haven. Assets are stored locally; the website makes no live Poly Haven API calls.

- Wood Table Large (diffuse + OpenGL normal, 2K): https://polyhaven.com/a/wood_table_large
- Potted Plant 01, Rico Cilliers (geometry, 1K textures): https://polyhaven.com/a/potted_plant_01
- Studio Small 09, Sergej Majboroda (reflection HDR, 1K): https://polyhaven.com/a/studio_small_09
- Joburg Central Sunset (window background HDR, 1K): https://polyhaven.com/a/sunset_jhbcentral
- Asset license: https://polyhaven.com/license

The desk, monitor, pedestal, keyboard, mouse, drawing tablet, stylus, lamp, cup, sketchbook, pencil, books, window and room are modeled in tools/build_office.py. No portfolio artwork is used as an alternate world or outside scenery in this revision.

Earlier comparison downloads (wood_table_001, wood_floor_deck) are unused source experiments, not shipped website assets.
